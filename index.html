    What to use

    "Will use" is the order it tries, and "Last time" is what answered and why it moved on. When your PC is on, Skybridge reads pages itself.

    Gemini

    Your key stays on this iPad. Page pictures go to Google when Gemini reads them.

    Gemini Live (experimental)

    The Live models have no daily request limit on the free key. Choose what is used at the top of this page. In Hybrid, with this on, naming pages and To text try a short Live session first (one picture in, the spoken answer read back as text) and use the usual Flash models only if that fails.

    With Live first, Live reads your page as JSON and the numbers are still checked exactly here. If Live's answer can't be used, Flash does it. Extended Thinking is best for this, and may take a minute or two.

    An opinion is a voice model reading the picture. It does not run the exact number check, so it is labelled unverified, never marks "Correct!", and can be wrong.

    Your key goes straight from this iPad to Google, as with Flash. Check my work and homework PDFs still use Flash, because they need exact structured answers that a voice model can't give reliably.

    Local model

    Your own model (Unsloth Studio, llama.cpp, Ollama, LM Studio...) at an OpenAI-compatible address. It is tried first, so Gemini's daily free requests last longer.

    No key needed when the server runs without one. Unsloth Studio with keyless access on your network needs none.

    A reasoning model can think for minutes before it answers. Fast mode asks it for low effort and no long thinking, if your server supports that. Check my work is much quicker.

    Words-only models write practice problems. A picture model also names pages, runs Check my work and To text. PDFs always use Gemini. The address and key stay on this iPad.
