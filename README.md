# Skybridge Board

The iPad whiteboard from Skybridge, as an installable web app. Open the address of this site in
Safari on the iPad, tap Share, then Add to Home Screen. It then works with no internet or PC and keeps
its notebooks on the iPad.

This folder is generated by `build_ipad_app.py` in the Skybridge project. It contains only the board:
no keys. If you add your own Gemini key in the app (optional, for page titles and Check without a PC), it stays on that iPad.
